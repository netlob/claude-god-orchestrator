# Wrap up

1. **Ask:** "Was anything decided today that is not written down yet?" If yes, write a decision note from `templates/decision.md` in the right place: the project's `decisions/`, or the home base `decisions/` when it is not about one project.
2. **Ask** whether there is thinking worth keeping: doubts, open questions, half-formed ideas. If yes, run save-my-thinking.
3. **Review what changed today** (Git status and diff). For each project touched, update "Where it stands" in its `CLAUDE.md` with today's date. Tick or update the seven-day tasks in `plan.md`.
4. **Check `inbox/`.** If items are waiting, offer to process them now or leave them for tomorrow.
5. **Write "Next up"** in `plan.md`: one to three lines on what to pick up next session.
6. **Save** with Git, with a plain-language message such as "Wrap up 2026-10-13: decided on the tour routing, updated the Ava Lin status".
7. **Tell them** in three lines what was saved and what is waiting for tomorrow.
