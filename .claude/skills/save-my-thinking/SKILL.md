# Save my thinking

1. **Decide where it belongs:** `projects/<name>/thinking/` when it is about one project, otherwise `me/thinking/`.
2. **Keep the original.** If the thinking arrived as a long dictation, first save it unchanged as a source: `sources/YYYY-MM-DD-dictation-<topic>.md` in the same place.
3. **Write the note** from `templates/thinking.md`: the topic, what they think right now, doubts, open questions, what would settle it. Use their own words and phrases; tidy only for readability. Do not add conclusions of your own, or mark them clearly as `— inferred`.
4. **Spot decisions.** If part of it is actually a decision, say so and offer to write a decision note.
5. **Read it back** in three lines and ask if it is right. Then save with Git.
