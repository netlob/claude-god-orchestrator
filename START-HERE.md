# Start here

This folder is your home base. Claude runs it for you; you talk, it does the work and writes things down. Three steps to get going.

## 1. Do the interview (about twenty minutes)

Open the `interview` folder and double-click `interview.html`. It opens in your browser and needs no internet. Turn on voice dictation and talk through each question. Your answers save as you type, so you can close it and come back. When you are done, click **Download my answers** and move the downloaded file into the `inbox` folder here.

If the page does not work for you, open `interview.md` instead, write under each question, and save it in `inbox`.

## 2. Open this folder in Claude Code

In the Claude app, go to the **Code** tab and open this folder. (Or, in Terminal: `cd` into the folder and type `claude`.)

## 3. Paste this message and talk

> [Talk for a few minutes about who you are, what you do, and what's on your plate.] This is my first session in my new home base. Read the briefing in this folder and start my onboarding. Take your time, show me the plan before you build anything, and prove it works with one real task of mine.

Claude reads your interview, asks follow-up questions, shows you a plan and builds your setup after you say go. Then it runs one real task with you so you see how it works.

## Good to know

- Claude sometimes asks permission before running something. If it is what you asked for, say yes.
- Say what you want in plain words. Claude knows these routines: **catch me up**, **wrap up**, **process my inbox**, **start a new project**, **save my thinking**.
- Files are the memory. Chats disappear, this folder stays. If something matters, ask Claude to write it down.
- Anything you want Claude to look at goes in `inbox`: transcripts, contracts, notes. Then say "process my inbox".
- Git keeps the history of this folder. Claude handles it; you never have to touch it.
